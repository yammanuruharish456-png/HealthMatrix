## 🎥 FILMING TIPS

### Camera Setup
- Use screen recording software (OBS, Camtasia, or ScreenFlow)
- Record at 1920x1080 resolution
- 30 FPS minimum
- Enable cursor highlighting

### Audio
- Use a good quality microphone
- Record in a quiet environment
- Speak clearly and at a moderate pace
- Add background music (optional, low volume)

### Editing
- Add transitions between sections
- Highlight important UI elements with zoom or arrows
- Add text overlays for key points
- Include timestamps in description

### Video Structure
1. **Intro** (0:00-2:00)
2. **Patient Demo** (2:00-7:00)
3. **Doctor Demo** (7:00-12:00)
4. **Admin Demo** (12:00-18:00)
5. **Features** (18:00-20:00)
6. **Technical** (20:00-22:00)
7. **Conclusion** (22:00-23:00)
